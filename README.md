# pr-lifecycle-demo-3

This repository is a **pull-request lifecycle demo** sandbox, used for the new-engineer onboarding session.

It holds a tiny Python script, `greeter.py`, that prints a greeting. During the demo we walk through the full lifecycle:

1. Create a feature branch (`feature/greeting-tweak`).
2. Change the greeting text to something friendlier.
3. Open a draft pull request into `main`.
4. Verify the pull request's change set, then mark it ready for review.

Nothing here is precious — this repo is disposable.
